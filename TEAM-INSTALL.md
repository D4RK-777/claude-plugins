# Install the Marketing Pipeline

3 steps. About 60 seconds. No technical knowledge.

---

## Before you start

You need **Claude Code** installed.
Don't have it? Get it here: https://docs.claude.com/en/docs/claude-code/quickstart

---

## Step 1 — Download the ZIP your admin sent you

The file is called `chatinc-plugins.zip`.

Save it somewhere you'll find it — `Documents` is fine.

---

## Step 2 — Unzip the file

**Mac:** Double-click the zip → it makes a folder called `chatinc-plugins/`
**Windows:** Right-click → "Extract All" → leaves a folder called `chatinc-plugins/`

---

## Step 3 — Open the `install` folder inside it, then double-click:

| Your computer | File to double-click |
|---|---|
| Mac | `install-mac.command` |
| Windows | `install-windows.bat` |

**Mac:** If Mac says "can't open because unidentified developer" → right-click → "Open" → "Open" again. (One-time security prompt.)
**Windows:** If Windows asks "Are you sure?" → "Run anyway".

A black window opens. Wait 20 seconds. When you see "Press Enter to close" → press Enter.

---

## Step 4 — Open Claude Code and type:

> install marketing command center

The dashboard installs. A link appears in chat. Click it.

**Done.**

---

## What you got

A Marketing Command Center dashboard. Click **+ New campaign**, fill 9 fields, AI does the rest.

Your campaign files go in `Documents/ChatInc-Marketing/`. You don't need to do anything with that folder — just know it exists.

---

## When the admin sends an updated version

1. Delete the old `chatinc-plugins` folder
2. Unzip the new one in the same place
3. Run the installer again (same file as before)

That's it. Your campaign data is safe — it lives in `Documents/ChatInc-Marketing/`, separate from the plugin folder.

---

## If something went wrong

**"Claude Code is not installed"**
Install it first: https://docs.claude.com/en/docs/claude-code/quickstart — then re-run.

**Mac says "unidentified developer"**
Right-click the file (or Control+Click), choose "Open" — then "Open" again on the prompt. One-time only.

**Nothing happened when I double-clicked**
Try right-click → "Open With" → Terminal (Mac) / Command Prompt (Windows).

**Anything else**
Ping `#marketing-ops` on Slack with a screenshot.
